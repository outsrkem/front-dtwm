# Vue 3 + Vite

This template should help get you started developing with Vue 3 in Vite. The template uses Vue 3 `<script>` SFCs, check out the [script setup docs](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) to learn more.

### Project Startup Instructions for Development Environment

Create Local Environment Configuration

Create a `.env.local` file and fill in the backend API server address as follows:

```
VITE_API_Endpoint=https://example.api.com:8998
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build Production Assets

```bash
npm run build
```

### Lint Code

```bash
npm run lint
```

### Lint Code & Auto-fix Fixable Issues

```bash
npm run lint:fix
```
